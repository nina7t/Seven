# Oracle Cloud Free Tier — Guide d'installation pour Sevenz

## 1. Créer un compte Oracle Cloud

1. Va sur [cloud.oracle.com](https://cloud.oracle.com)
2. Clique sur **Start for free** / **Commencer gratuitement**
3. Connecte-toi avec un compte Google ou cree un compte Oracle
4. **Verification par carte bleue** : Oracle demande une carte pour vérifier que tu n'es pas un bot — tu ne seras PAS débité (c'est gratuit, le free tier ne facture rien)
5. Une fois verified, choisis ta region (Frankfurt, Paris, etc.)

---

## 2. Créer une VM (Instance)

1. Dans le dashboard Oracle Cloud, cherche **Compute** → **Instances**
2. Clique **Create instance**
3. Configure :
   - **Name** : `sevenz-proxy`
   - **Location** :，选择 ta région la plus proche (Frankfurt recommended for Europe)
   - **Image** : `Ubuntu 22.04` (ou 24.04 LTS)
   - **Shape** : cherche une shape gratuite
     - Si tu as un nouveau compte : **Ampere** (ARM) gratuit
     - Si tu as un ancien compte : **VM.Standard.E2.1.Micro** (x86) gratuit
   - **SSH Keys** : génère une paire de clés SSH avec `ssh-keygen -t ed25519` sur ton Mac, ou choisis "Generate SSH Keys" et download la clé privée
   - **Networking** : laisse par défaut (il va créer un VCN automatique)
4. Clique **Create** et attend 2-3 minutes que l'instance démarre

---

## 3. Récupérer l'IP publique

1. Une fois l'instance créée, tu verras l'**IP publique** (ex: `132.145.89.234`)
2. **Copie cette IP** — tu en auras besoin pour SSH et pour l'app

---

## 4. Se connecter en SSH

Sur ton Mac :

```bash
chmod 600 ~/Downloads/your_key.pem   # ou là où tu as sauvegardé la clé
ssh -i ~/Downloads/your_key.pem ubuntu@132.145.89.234
```

> ⚠️ Remplace `your_key.pem` par le nom réel du fichier téléchargé

Si tu as une erreur "Permission denied", c'est probablement les droits sur la clé :

```bash
chmod 400 ~/Downloads/your_key.pem
```

## 5. Installer tout d'un coup

Copie-colle ce script sur ta VM (après t'être connecté en SSH) :

```bash
# ══════════════════════════════════════════════════════════════
# Script d'installation — Sevenz Proxy Server
# À exécuter sur la VM Oracle Cloud Ubuntu 22.04
# ══════════════════════════════════════════════════════════════

set -e

echo "🚀 Installation du serveur Sevenz..."

# ─── Mise à jour ───
sudo apt update && sudo apt upgrade -y

# ─── Node.js 20 LTS ───
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# ─── yt-dlp + ffmpeg + Python (pour yt-dlp) ───
sudo apt install -y python3 python3-pip ffmpeg
pip3 install yt-dlp --break-system-packages

# ─── pm2 (gestionnaire de processus) ───
sudo npm install -g pm2

# ─── Vérifications ───
echo ""
echo "✅ Vérifications :"
node --version
npm --version
yt-dlp --version
ffmpeg -version | head -1
pm2 --version
echo ""

# ─── Créer le dossier de l'app ───
sudo mkdir -p /opt/sevenz-proxy
sudo chown ubuntu:ubuntu /opt/sevenz-proxy

# ─── UFW Firewall ───
sudo ufw allow 22/tcp comment 'SSH'
sudo ufw allow 3001/tcp comment 'Sevenz Proxy'
sudo ufw --force enable

echo ""
echo "✅ Installation terminée !"
echo "📁 Code à déployer dans : /opt/sevenz-proxy"
echo "🔒 Firewall configuré (port 3001 ouvert)"
echo ""
echo "Prochaine étape :"
echo "  1. Transfère ton code server.js sur la VM"
echo "  2. Installe les dépendances : cd /opt/sevenz-proxy && npm install"
echo "  3. Ajoute le fichier cookies.txt (voir section Cookies)"
echo "  4. Démarre : pm2 start server.js --name sevenz"
```

## 6. Transférer le code sur la VM

Sur **ton Mac** (pas sur la VM), dans le dossier du projet :

```bash
# Copie le dossier server vers la VM
scp -i ~/Downloads/your_key.pem -r ./server/* ubuntu@132.145.89.234:/opt/sevenz-proxy/

# Ou si le dossier distant n'existe pas encore, crée-le d'abord :
ssh -i ~/Downloads/your_key.pem ubuntu@132.145.89.234 "sudo mkdir -p /opt/sevenz-proxy && sudo chown ubuntu:ubuntu /opt/sevenz-proxy"
scp -i ~/Downloads/your_key.pem -r ./server/* ubuntu@132.145.89.234:/opt/sevenz-proxy/
```

## 7. Configurer les variables d'environnement

Sur la VM :

```bash
cd /opt/sevenz-proxy

# Crée le fichier .env
nano .env
```

Contenu minimum :

```
YOUTUBE_API_KEY=TA_CLE_API_YOUTUBE
YOUTUBE_API_KEY_2=TA_CLE_2
YOUTUBE_API_KEY_3=TA_CLE_3
PORT=3001
```

 Sauvegarde avec `Ctrl+X`, puis `Y`, `Enter`.

## 8. Cookies YouTube (IMPORTANT pour éviter les bans)

Sur **ton Mac** :

1. Installe l'extension "EditThisCookie" dans Chrome
2. Va sur YouTube.com et connecte-toi
3. Clique sur EditThisCookie → Export → copie le JSON
4. Convertis en format Netscape (cookies.txt) avec ce script Python :

```python
# Sauvegarde ce script sur ton Mac et exécute-le
import json
import sys

json_cookies = json.loads(sys.stdin.read())

lines = ["# Netscape HTTP Cookie File", "# This file was generated by EditThisCookie"]
for c in json_cookies:
    domain = c.get('domain', '.youtube.com')
    flag = 'TRUE' if not c.get('hostOnly', False) else 'FALSE'
    tail = 'TRUE' if c.get('secure', False) else 'FALSE'
    expires = int(c.get('expirationDate', 0))
    path = c.get('path', '/')
    name = c.get('name', '')
    value = c.get('value', '')
    lines.append(f"{domain}\t{flag}\t{path}\t{tail}\t{expires}\t{name}\t{value}")

print('\n'.join(lines))
```

Enregistre dans `cookies_netscape.py`, puis :

```bash
# Exporte les cookies depuis EditThisCookie (copie le JSON), puis :
echo '[colle le JSON ici]' | python3 cookies_netscape.py > cookies.txt
```

Transfère sur la VM :

```bash
scp -i ~/Downloads/your_key.pem cookies.txt ubuntu@132.145.89.234:/opt/sevenz-proxy/cookies.txt
```

## 12. Ouvrir le firewall Oracle Cloud (TRÈS IMPORTANT)

C'est l'étape que tout le monde oublie et qui bloque tout.

### Via la console Oracle Cloud :

1. Va sur ta **Instance** dans Oracle Cloud
2. Clique sur le nom de la **Subnet** (dans les détails de l'instance)
3. Clique sur le **Security List** associée
4. Clique **Add Ingress Rules** :

```
Direction : Ingress
Source Type : CIDR
Source CIDR : 0.0.0.0/0
IP Protocol : TCP
Destination Port Range : 3001
Description : Sevenz Proxy Stream
```

5. Sauvegarde

### Vérifier avec :

```bash
# Depuis ton Mac :
curl http://132.145.89.234:3001/api/health
```

Si ça marche → l'IP publique est accessible. 🎉

## Si tu veux un domaine (optionnel)

Tu peux pointer un domaine (ex: `proxy.tondomaine.com`) vers l'IP Oracle avec un record A dans ton DNS.

Pour HTTPS, utilise **Cloudflare** (gratuit) qui fait proxy HTTPS gratuit :
1. Ajoute ton domaine sur Cloudflare
2. Crée un record A pointant vers `132.145.89.234`
3. Active le proxy Cloudflare (orange)
4. Cloudflare fournit un certificat SSL automatique
